# 鯉魚創意專題誌：資料更新要求

## 資料原則

1. 專題內容以 `projects.json` 為主要來源。
2. 不得自行杜撰專題名稱、技術、獎項、學生姓名或指導教師。
3. 未確認欄位顯示「待補」或不顯示。
4. `verificationStatus` 為 `pending` 或 `partial` 時，可在管理或開發模式顯示提醒。
5. 同一作品參加不同競賽時，獎項必須分別呈現。
6. 未得獎作品仍需正常展示。
7. 全站使用繁體中文。

## 首頁固定內容

- 網站名稱：鯉魚創意專題誌
- 主標題：動手玩創意
- 副標題：從生活問題出發，讓孩子用科技、文化與創意改變世界
- 預設主題：森林生態風
